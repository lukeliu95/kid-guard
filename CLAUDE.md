## Project Identity

**kid-guard** is a Chrome MV3 browser extension. Parental control for kids age 12-15. Blocks games / adult / short-video / gambling / gacha / VPN / addictive sites. Local-only, zero outbound data.

Generated by GEI Agent on 2026-05-05. v1 spec: 18 REQ across 13 modules, 0 LLM, vanilla HTML/CSS/JS, Superhuman visual reference.

## Hard Rules (do not violate)

1. **CSS comments must be ASCII-only.** Tailwind v4 + lightningcss silently drops rules after a non-ASCII CSS comment (pitfall-20260417). Even though we don't use Tailwind, this is a defensive habit. Pre-commit hook recommended:
   ```bash
   git grep -n -P '/\*[^*]*[^\x00-\x7f]' '*.css' && exit 1 || true
   ```

2. **Zero outbound network.** No fetch / XMLHttpRequest / WebSocket to any non-extension origin. The only fetch allowed is `fetch(chrome.runtime.getURL(...))` for local resources. Verify with `grep -E 'fetch\(|XMLHttpRequest|WebSocket' extension/`.

3. **PIN gate enforcement is server-side.** UI must NOT bypass; any mutating message handler in service-worker.js MUST `await pinGuard.requirePinUnlocked()` before doing the mutation. Reply `{ok:false, error:"PIN_REQUIRED"}` if not unlocked.

4. **Bundle size budgets are hard.** See module-contracts.md section 8. If `build.sh` reports any over-budget artifact, the build is failed. Don't bypass.

5. **declarativeNetRequest enum = ruleset_id (pattern-20260427-130200).** CATEGORY_IDS array literal must equal RULESET_IDS array literal must equal manifest.declarative_net_request.rule_resources[*].id. Any drift is a silent block-miss bug.

6. **Blocked page DOM injection uses textContent only (pitfall-20260416).** Hostnames and queries are user-influenced; never `innerHTML`. Manual escape via textContent.

7. **No npm dependencies.** Service workers in MV3 can't load node modules. Vanilla only. If build tooling is needed (esbuild for minify), it stays out of the runtime bundle.

8. **All code comments in English.** Reduces collision with rule 1 above (CSS) and stays consistent.

## How to develop

Pre-reqs: Chrome 111+, bash, optional `imagemagick` or `python3-pil` for icon regen, optional `node` for `--check` syntax verify.

```bash
# from repo root
cd extension/

# load unpacked: chrome://extensions -> developer mode -> load unpacked -> select dist/ (or extension/ for live edit)

# build a release zip
bash build.sh
# produces ../kid-guard.zip and prints size table
```

Live development:
- chrome://extensions -> developer mode -> load unpacked extension/ (no build needed)
- Click reload on the card after JS changes
- Service worker: open chrome://extensions -> KidGuard -> "service worker (active)" link to inspect

Testing manually:
- Visit any domain in ruleset/games.json -> expect redirect to blocked.html
- chrome.alarms heartbeat: open service worker devtools -> wait 60s -> see schedule-lock.evaluate() log
- PIN: clear storage (chrome.storage.local.clear() in popup console) -> reopen -> onboarding fires

## Commands you'll likely use

```bash
# size check
du -sh extension/{popup,options,blocked,onboarding,background,shared,ruleset,data,icons}

# JSON validity
python3 -c "import json,glob;[json.loads(open(f).read()) for f in glob.glob('extension/**/*.json',recursive=True)]"

# CSS comment ASCII check
git grep -n -P '/\*[^*]*[^\x00-\x7f]' 'extension/**/*.css'

# outbound fetch grep
grep -rE 'fetch\(|XMLHttpRequest|new WebSocket' extension/ \
  | grep -v 'chrome.runtime.getURL' \
  | grep -v '//.*' \
  || echo "OK: no outbound fetch"
```
