欢迎使用 KidGuard

这是一个家庭友好的浏览器拦截扩展, 帮助孩子专注学习。

  • 1060 个内置网站分 7 类自动拦截 - 游戏 / 成人 / 短视频 / 抖音类 / 赌博 / 抽卡充值 / VPN 代理
  • 关键词拦截覆盖 Google / Baidu / Bing 三大搜索引擎
  • 时段锁支持作息时间(如 22:00-06:00)整段不可上网
  • PIN 守门只有家长能改设置, 孩子无法自行解除
  • 零数据外传 - 所有规则与记录仅在本机, 不上传任何服务器

下面 6 步会引导你完成所有初始设置, 全程约 3 分钟。

设置 4-6 位 PIN

这个 PIN 用来保护设置 - 只有输入它的人(你)才能改黑名单、关分类、改时段。请输入 4-6 位数字, 牢牢记住。

再输一次确认

两次输入需完全一致, 防止笔误锁死自己。

设置退出问题

如果哪天忘了 PIN, 答对此问题可在 onboarding 页面重设。问题和答案都不会上传, 仅本机存哈希。

选择拦截分类

默认全部启用。如果某类不想拦截, 取消勾选即可 - 后续可在管理后台随时调整。

  • 200 个网站 - 4399 / steam / epicgames / riotgames / 国内主流游戏官网等

  • 210 个网站 - 主流成人视频站点 + 中日韩限制级聚合站

  • 100 个网站 - 微博 / 小红书 / Instagram / TikTok 等

  • 80 个网站 - 抖音 / 快手 / 西瓜视频 / 火山等

  • 220 个网站 - bet365 / 在线赌场 / 体育博彩站

  • 100 个网站 - 涉赌开箱站 + 第三方代充

  • 150 个网站 - 主流 VPN 与机场代理(防绕过用)

高级设置 (可选)

这两项都可以跳过, 后续在管理后台随时添加。

额外屏蔽特定网站

每行一个域名, 例如 bilibili.com。无需带 https:// 前缀。

作息时段锁

每天生效。跨午夜支持 (例如 22:00 - 06:00 表示晚上 10 点到次日早上 6 点)。

设置完成

所有规则已生效。

现在 只有你(家长)能修改这些设置 - 孩子打开管理后台会被 PIN 锁住。

点击工具栏上的 KidGuard 图标可以随时查看 7 天拦截报表。

未完成 PIN 设置无法跳过 - 关闭页面后下次仍会回到这里
