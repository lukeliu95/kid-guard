# KidGuard 安装指南(给父母看)

KidGuard 是一个本地的 Chrome 浏览器扩展,帮助孩子专注学习。所有数据都只保存在本机,不会上传到任何服务器。

## 前置条件

- 一台安装了 Chrome 浏览器(版本 ≥ 111)的电脑
- 你已经收到了一份 `kid-guard.zip`(压缩包)

## 安装步骤

### 1. 解压

把 `kid-guard.zip` 解压到一个**长期存放**的位置,例如:

- macOS: `~/Documents/kid-guard/`
- Windows: `C:\Users\<你的用户名>\Documents\kid-guard\`

> 注意:扩展加载后会一直引用这个目录里的文件。如果你之后删了这个目录,扩展就会失效。

### 2. 打开 Chrome 扩展管理页

在 Chrome 地址栏输入:

```
chrome://extensions
```

回车。

### 3. 打开"开发者模式"

在页面的**右上角**,把"开发者模式"开关切到**打开**(蓝色)。

### 4. 加载扩展

点击页面左上角的 **"加载已解压的扩展程序"** 按钮 → 选择上一步解压出来的 `dist/` 目录(或者解压根目录,如果不带 dist 子目录) → 点击"选择"。

KidGuard 应该出现在扩展列表里,图标会显示在 Chrome 工具栏。

### 5. 设 PIN

第一次安装时,Chrome 会自动打开 KidGuard 的引导页(onboarding),要求你:

- 设一个 4-6 位数字的 PIN(只有你知道,改名单/关分类要用)
- 设一个**找回问题** + 答案(万一忘了 PIN 用)

按提示设完即可。

### 6. 检查

- 点工具栏的 KidGuard 图标 → 看到周报面板说明扩展正常运行。
- 试着访问 `https://www.4399.com` → 应该跳转到拦截页 → 说明拦截规则在生效。

## 日常使用

- **看周报**:点工具栏 KidGuard 图标。
- **改名单 / 调时段锁 / 改关键词**:在扩展管理页点 KidGuard 的"详情" → "扩展程序选项",或者直接右键 KidGuard 图标 → "选项"。
- 每次进入"选项"页改东西,都需要先输 PIN(5 分钟内有效)。

## 卸载

回到 `chrome://extensions`,在 KidGuard 一栏点"移除"即可。所有本地数据会一并清除。

## 常见问题

**Q: 我忘了 PIN 怎么办?**
A: 在选项页或锁屏页点"忘了 PIN" → 回答你设过的找回问题 → 重新设新 PIN。

**Q: 扩展会上传孩子的浏览记录吗?**
A: 不会。KidGuard 不发任何外部网络请求,所有数据(包括拦截记录、访问统计)都只在本机的 chrome.storage.local 里,卸载就清空。

**Q: 我能不能让某个网站豁免拦截?**
A: 在"选项 → 白名单"里加这个域名(需要 PIN)。白名单优先级高于内置黑名单。

**Q: 时段锁里"22:00–06:00"是跨天的吗?**
A: 是。从当晚 22:00 一直到第二天早上 06:00 全部拦截。

**Q: Chrome 提示"该扩展未通过审核"怎么办?**
A: 这是因为 KidGuard 是以"开发者模式"加载的本地扩展,不在 Chrome 应用商店上架(为了保护隐私不上架)。提示忽略即可。
